so many commands

November 10, 2026

Just finished Sec18 for my AWS exam study which covered CloudFormation. This is basically a document that declaratively lets you provision AWS resources so you don't have to work in the UI. The pros are that you have this code, can version control. There's a template you have to follow but there are all of these commands that we have to know for the exam. !Ref means a reference in your YAML document to resources or parameters that are returned. !FindInMap means you can look up values in a static mapping table which plugs into your template. There's !GetAtt which means getting attributes from resources. It's a lot ngl and less intuitive than other sections of this course.
