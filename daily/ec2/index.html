I can't summarize EC2 better than that but in case you are needing additional details, here they are:

The EC2 instance is a virtual server that runs in the AWS Cloud. You can add a user-data script so that commands you need i.e. installing updates or software can be run as soon as you start an instance, can only do this at the beginning of starting an instance.

There's an ungodly amount of options: 1) on demand instances - short-term, and cannot be interrupted 2) reserved comes in 1, 3 year plans options 1) standard reserved instance - where you can reserve for workloads. cannot change EC2 instance family but bigger discount. 2) convertible reserved where you can reserve for workloads but those that might change types so this one lets you change EC2 instance type 3) savings plan also comes in 1, 3 year plans options and here, you commit to a $ amount 4) spot instances - cheap but can be interrupted i.e. 90% off but 2 minute warning in case your instance is turned off. 5) dedicated hosts - you can have an entire server to yourself, hurrah! 6) dedicated instance - you get an instance but cannot control the server location. 7) capacity reservation - you get on-demand capacity but you are billed regardless if you use or not. tied to a single availability zone.
