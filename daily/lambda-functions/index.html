lambda functions

November 13, 2026

Covered Lambda functions today. It's a pretty major topic for the AWS exam.

The main feature about Lambda functions is that it's serverless, which means you do not have to manage a server. You, as a client can trigger the function to get some information back which is the synchronous approach. You as the caller have to wait for the Lambda to return back information. The alternative is the asynchronous approach where the caller will invoke the Lambda but not need the output back i.e. if there's an event that causes the Lambda to be triggered, the output from the Lambda could go somewhere else i.e. destinations. For Lambda to access other applications i.e. S3 file or SNS or something else, it needs the execution role. Event source mappings may be needed for polling. But for other applications to call Lambda, they need to be added to the Resource based policy for Lambda.

There's some limits that have to be known for the exam:

  • there's a 10G maximum for memory allocation
  • there's a 15 minute maximum execution time
  • environmental variables possible are only allowable upto 4 KB
  • disk capacity in the temporary folder is up to 10 GB
  • concurrent executions are 1000 (but these can be increased)
