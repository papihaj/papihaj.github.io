elastic container service summary

November 9, 2026

Back to AWS content with exam looming soon. Learned about ECS today and finished that lecture for AWS. ECS refers to Elastic Container Service and this service lets you manage and control the different tasks/containers you will be running. ECS runs on a cluster which means that ECS decides where the tasks will go i.e. which machine will run your task. ECS is similar to Docploy that I had used earlier to manage my Docker container. 2 ways that tasks can run:

  • EC2 launch type which is where you manage the instances
  • Fargate: serverless
